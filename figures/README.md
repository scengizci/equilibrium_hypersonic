# Figures

- `domain.tex` — standalone TikZ source of the computational domain
  (Figure 1 of the manuscript); compile with `pdflatex domain.tex`.
- `domain.pdf` / `domain.png` — compiled versions of the domain figure.
- `mesh_full.png` — full view of the unstructured mesh
  (23,934 nodes, 47,264 triangular elements).
- `mesh_zoom.png` — close-up of the constant-thickness element layers
  near the cylinder.

Additional output figures (contour plots, cross-sections, difference maps,
training diagnostics) will be added together with the code release.
