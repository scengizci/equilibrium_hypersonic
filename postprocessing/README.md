# Post-processing scripts

**Status: to be uploaded.**

Scripts used to generate the results reported in the manuscript:

- contour plots of M/M∞, p/p∞, T/T∞, ρ/ρ∞ (FEM vs. PASSC),
- cross-section comparisons (vertical slice through the bow shock and wake
  centerline),
- pointwise PASSC − FEM difference maps,
- 3D surface representations of the Mach-number field,
- bow-shock stand-off detection and stagnation-pressure evaluation
  (Billig correlation and Rayleigh pitot references),
- training-diagnostic plots (loss components and weight schedule).
